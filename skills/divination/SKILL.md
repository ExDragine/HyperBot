# 易经与塔罗

- 按用户指定的方法调用 `iching_divination`。查询卦象用 `list_iching_hexagrams` 或 `get_hexagram_detail`。
- 塔罗解读用 `tarot_reading`。用户询问可用牌阵时用 `list_tarot_spreads`。
- 将解读呈现为象征或反思，涉及医疗、法律、财务或安全决策时依据可核实信息。
